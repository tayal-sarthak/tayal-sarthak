One-Liners about a few repos:<br>
\
**Braindecode**: Deep Learning library on EEG data making training neural networks on brain signals faster.<br>
**NeuroScope**: A neural data viewer allowing researchers to locally view EEG data with no subscriptions.<br>
**edf2csv**: A conversion tool transforming EEG files(.edf) to CSV files(.csv) for usage in standard tools.<br>
**edfcore**: A TypeScript library designed to handle the manipulation of standardized European Data Format (.edf) files.<br>
**Connect Me Tutoring**: Biggest student-run tutoring platform in the U.S: free with over 5,000 users.
